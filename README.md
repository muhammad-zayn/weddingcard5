# Saina & Nizamuddin — Cinematic Nikkah Invitation

A framework-free, production-ready digital wedding invitation built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5 (CDN, responsive utilities only)
- CSS keyframe animations for the cinematic satin curtain
- HTML5 Audio for a short, user-triggered curtain reveal sound

## Run

No build step is required.

You can open `index.html` directly, or serve the folder with any static web server.

## Deploy

The project can be deployed directly to Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any static host.

## Main files

- `index.html` — page structure/content
- `styles.css` — all styling and responsive visuals
- `script.js` — curtain animation, reveals, countdown, scratch interaction, RSVP and audio
- `assets/` — reserved for optional future image assets

## Customize

Search `index.html` for names, event details, family names and Google Maps URLs.

The countdown target is in `script.js`:
`2026-09-18T00:00:00`

### Curtain audio
`assets/curtain-reveal.wav` is a short, locally bundled, low-volume reveal sound triggered by the Open Invitation button.
